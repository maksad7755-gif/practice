# Finance Tracker

A beginner Python project for calculating income, expenses, and net profit.

## Features

- Enter financial data for any number of days
- Calculate daily net profit
- Calculate total net profit
- Run another calculation without restarting the program

## How to run

1. Install Python 3.
2. Download this repository.
3. Run the command below:

```bash
python finance_tracker.py
```

## Example

```text
1-kun daromadini kiriting: 100000
1-kun xarajatini kiriting: 40000
1-kun sof foydasi: 60000 so'm
```
